# Notebooks

Three tiers:

1. **`pipeline/00–14` — canonical. Start here.** One self-contained notebook
   per pipeline stage (see [`pipeline/README.md`](pipeline/README.md)).
2. **Themed folders** (`analysis/`, `mars/`, `training/`, `diagnostics/`,
   `presentation/`, `interpretation/`) — supporting / historical material,
   no longer the canonical reference.
3. **`archive/`** — frozen history; kept for provenance, do not maintain or
   import from.

New reader? Open these three first:

1. [`pipeline/00_project_setup_and_assumptions`](pipeline/00_project_setup_and_assumptions.ipynb) — paths, regimes, units, assumptions
2. [`pipeline/04_earth_mars_regime_calibration`](pipeline/04_earth_mars_regime_calibration.ipynb) — how the Earth regimes were calibrated against Mars
3. [`pipeline/12`](pipeline/12_mars_threshold_and_prediction_analysis.ipynb)–[`13`](pipeline/13_scientific_interpretation.ipynb) — the Mars result and its scientific interpretation

Full catalogue (every notebook, per-folder tables) and the **Kernels** note
(how to run notebooks against the `ch-heads` conda env) live in
[`docs/notebooks.md`](../docs/notebooks.md).
