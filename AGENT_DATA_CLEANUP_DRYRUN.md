## Regeneration priority order

When a retrain decision is made, the correct order is:

```
1. Earth rasters (regime patch-builder)
2. Earth CNN training (train_cnn_baseline / regime)
3. Earth combined-XGBoost training (train_combined_xgb_*)
4. Mars patches (run_mars_pipeline.py --stage patches)
5. Mars embeddings (--stage embeddings)
6. Mars combined inference (--stage combined)
```

Geometry-only XGBoost models and Mars tabular features (Phase 3A) are
unaffected and do not need to be regenerated.
